# Visual Direction

## Experience Goal

Create a polished, intentional product experience — not a generic template or noisy dashboard.

Desired emotional profile:
- Clear
- Warm (when the palette calls for it)
- Trustworthy
- Restrained
- Content-first

## Core Aesthetic Principles

1. Primary content (data, media, or copy) is always the main visual focus.
2. Interface chrome should be subtle and restrained.
3. Typography and spacing should feel deliberate and readable.
4. Secondary actions and commerce controls should be integrated, not dominant.
5. Every section should preserve visual breathing room.

## Color Direction

Primary background tones:
- Soft warm white
- Light neutral surfaces
- Very light stone or gray tints

Text tones:
- Charcoal or near-black for primary readability
- Muted gray-brown or gray for secondary text

Accent tones:
- Soft sand/beige or a single restrained brand accent
- No loud saturation in default UI accents

Rule:
- UI colors must not compete with primary content (images, charts, hero media, or dense data).

## Typography Direction

Role-based typography:
- Display/section headings: clear hierarchy with refined contrast
- Body copy: readable face with comfortable line length
- Utility labels/buttons: understated, medium weight, high legibility

Guidance:
- Prefer modest font sizes with generous line-height
- Avoid heavy, loud, or condensed UI typography unless the brand explicitly requires it

## Media and Imagery Direction

1. Keep hero and card media large and clean, with minimal overlays.
2. Preserve color fidelity; avoid aggressive filters on user-facing content.
3. Use crop and aspect-ratio strategies that respect the subject.
4. Thumbnails and previews should remain legible at small sizes.

## Tone of Interface

1. Calm, confident, purposeful.
2. Minimal ornamental effects.
3. Motion should be subtle and deliberate.
